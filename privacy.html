Política de privacidad

Versión 1.0 · última actualización: 29 de septiembre de 2026

Livre («Livre», «nosotros») permite solicitar un viaje y consultar su estado y ubicación mediante un enlace privado. Esta política explica qué datos se procesan en la app de pasajeros.

Datos que se solicitan

  • Nombre del pasajero.
  • Dirección de origen y destino ingresadas para el viaje.
  • Datos técnicos mínimos necesarios para atender la solicitud y mostrar el seguimiento.
  • Un token privado de seguimiento, incluido en el enlace del viaje.

La app no solicita una cuenta, contraseña ni acceso al micrófono, cámara, contactos o ubicación del dispositivo. El origen y destino son datos escritos por la persona usuaria.

Para qué se usan

Se usan para crear y gestionar el pedido, asignar un conductor disponible, mostrar el estado del viaje y actualizar el mapa de seguimiento. No se venden datos personales ni se usan para publicidad personalizada.

Con quién se comparten

Los datos se procesan en la infraestructura de Livre Cloud y se muestran únicamente a los sistemas y personas que necesitan operar el viaje. El enlace privado permite consultar el viaje; no debe compartirse públicamente.

Conservación y seguridad

Se conservan durante el tiempo necesario para operar, resolver reclamos y cumplir obligaciones legales. El acceso se protege con HTTPS y tokens privados. Ningún sistema conectado a Internet puede garantizar seguridad absoluta.
